# Early work

Programs and teaching material by Łukasz Stafiniak from 2003 to 2012, recovered from an old Dropbox in November 2026. Nothing here is maintained, and most of it will not build with current tools. It is kept as a record.

| Folder | Years | Language | What it is |
|---|---|---|---|
| [ox4d](ox4d) | 2003–2007 | OCaml, LablTk | Noughts-and-crosses in four dimensions, with a computer opponent |
| [ocamlode](ocamlode) | 2005 | OCaml, C | Bindings to the Open Dynamics Engine, with a camlp4 syntax extension |
| [bzu](bzu) | 2005–2006 | ST6 assembly | Firmware for an electrical safety circuit monitor and breaker, with Piotr Stafiniak |
| [labs/neural-networks](labs) | 2005–2006 | Matlab | Laboratory code for a neural networks course |
| [pmwiki-mode](pmwiki-mode) | 2007 | Emacs Lisp | An Emacs mode for editing PmWiki pages, releases 0.3 to 0.5rc2 |
| [luasteer](luasteer) | 2007 | C++, Lua | Lua bindings for the OpenSteer steering library |
| [coq-talk-2008](coq-talk-2008) | 2008 | slides | A seminar talk, "Coq as a Tutor in Formal Reasoning" |
| [labs/data-mining](labs) | undated | R, Octave | Slides and exercises for a data mining laboratory |
| [labs/evolutionary-algorithms](labs) | undated | Matlab, Octave | Laboratory code for an evolutionary algorithms course |
| [java-course](java-course) | 2011–2012 | Java | Exercises and own code from a course of programming in Java |

## Provenance and licences

Each folder has a README saying what in it is the author's and what it builds on. Each file keeps the licence notice it came with.

`luasteer` and the author's own files in `ocamlode` are under the MIT licence; see the `LICENSE` file in each. `pmwiki-mode` is under the GPL. The other folders have no licence: they may be read, and using the code needs permission.

Other people's material that sat beside these files is not included: textbook example code, other lecturers' slides, bundled libraries, datasets and papers.
