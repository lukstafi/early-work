# Course of Programming in Java (2011–2012)

Material from a course designed, lectured and run in the laboratory at the Institute of Computer Science, University of Wrocław, in the winter semester of 2011–12. The course was given in English.

## What is here

- `exercises/`: the first three exercise sheets (Self-Avoiding Walk, Classes and Objects, Sets and Maps), with TeXmacs sources where they survive.
- `settlers/`: a simulation in the style of the game The Settlers, written for the course. Castles, warehouses, flags and road segments form a network; carriers move goods along it; a scheduler drives the simulation. A world is described in a text file (`TestSetup.txt`) and the state can be saved and restored by serialization. `Main.java` is unfinished: a Swing interface was begun in it.
- `sets-and-maps/`: sets and maps implemented over a linked list, for the third exercise.
- `lecture-examples/`: the small examples written for lecture 6, on overriding and return types (`Lec6.java` to `Lec6e.java`). `Lec6.java` shows why an overriding method may not widen its return type.

## What is not here

The lecture slides are not included. Most lectures followed a textbook closely: *The Java Programming Language* by Arnold, Gosling and Holmes, *The Java Tutorials*, *Thinking in Java* by Bruce Eckel, *Head First Design Patterns*, and *Effective Java* by Joshua Bloch. The example code from those books that was used in class is not included either, nor are the per-lecture files that collected it.
